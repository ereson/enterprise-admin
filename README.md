## 📌 项目简介

**Enterprise Admin** 是一个基于 Java Spring Boot 构建的企业级通用后台管理系统，提供完整的权限管理、业务管理与系统基础能力，支持快速二次开发与企业级项目落地。

该系统目标是帮助开发者或企业**快速搭建后台管理平台，降低重复开发成本，提高交付效率。**

---

## 🚀 项目定位

* 企业级后台管理系统脚手架
* 可扩展的通用管理平台
* 支持快速二开 / 定制开发
* 可作为 SaaS / 内部系统基础框架

---

## 🏗️ 技术架构

### 后端

* Java 17+
* Spring Boot
* Spring Security / JWT（权限认证）
* MyBatis / MyBatis Plus（持久层）
* Redis（缓存 / 会话）
* MySQL（数据存储）

### 前端（可选）

* Vue3 / React（二选一）
* Element Plus / Ant Design Vue

### 基础设施

* Maven 多模块架构
* RESTful API 设计
* Docker 支持（可选）

---

## 🔐 核心功能模块

### 1️⃣ 权限系统（核心）

* 用户管理
* 角色管理
* 权限（菜单 + 按钮级）
* JWT 登录认证
* 动态权限控制

---

### 2️⃣ 系统管理

* 系统参数配置
* 字典管理
* 日志管理（操作日志 / 登录日志）
* 文件上传管理

---

### 3️⃣ 业务基础能力

* 通用 CRUD 体系
* 分页查询封装
* 统一异常处理
* 统一返回体设计

---

### 4️⃣ 可扩展能力（重点）

* 插件式模块设计（可扩展业务）
* 模块化开发结构
* 支持多业务系统集成

---

## 📦 项目结构建议

```text
enterprise-admin
├── admin-common        # 公共工具模块
├── admin-system        # 系统核心模块（用户/权限）
├── admin-framework     # 框架层（安全/配置/拦截器）
├── admin-api           # 对外API层
├── admin-service       # 业务逻辑层
└── admin-ui (optional) # 前端项目
```
